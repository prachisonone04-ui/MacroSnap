# 🥗 MacroSnap — AI Nutrition & Meal Tracking Assistant

MacroSnap is an AI-powered nutrition assistant that helps users understand their meals, estimate calories and macronutrients, and get personalized nutrition guidance using **Google Gemini AI**.

## 🚀 Live Demo

👉 **Try MacroSnap:** [prachisonone04-ui-macrosnap-app-vgu55e]
👉 **[Try MacroSnap](https://prachisonone04-ui-macrosnap-app-vgu55e.streamlit.app)**


## ✨ Features

* 🤖 AI-powered food and nutrition assistance
* 📸 Meal image analysis using Gemini Vision
* 🔥 Calorie estimation
* 💪 Protein, carbohydrates, and fat estimation
* 💬 Ask nutrition-related questions through AI chat
* 📱 Send meal details through WhatsApp using Twilio
* 🥗 Personalized nutrition guidance
* 🎨 Simple and user-friendly Streamlit interface

## 🛠️ Technologies Used

* **Python**
* **Streamlit**
* **Google Gemini API**
* **Twilio WhatsApp API**

## ⚙️ How It Works

1. Enter your basic details.
2. Ask a food or nutrition question.
3. Upload a meal image for AI analysis.
4. MacroSnap analyzes the meal using Gemini AI.
5. Get estimated calories and macronutrients.
6. Use the AI-generated nutrition guidance to understand your meal.

## 💻 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/prachisonone04-ui/MacroSnap.git
cd MacroSnap
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure API Keys

Add your API keys to Streamlit secrets:

```toml
GEMINI_API_KEY = "your_gemini_api_key"
TWILIO_ACCOUNT_SID = "your_twilio_account_sid"
TWILIO_AUTH_TOKEN = "your_twilio_auth_token"
```

### 4. Run the application

```bash
streamlit run app.py
```
