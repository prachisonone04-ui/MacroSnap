# MacroSnap

MacroSnap is an AI-powered nutrition and meal tracking application.

## Features

- AI-powered food and nutrition assistance
- Meal and macro tracking
- Personalized nutrition guidance
- Simple and user-friendly interface

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- Twilio

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
